# GDI FutureWorks: Реестр сторонних сервисов 🌐

Данный документ содержит полный список внешних API и сервисов, интегрированных в проект GDI FutureWorks, с указанием их назначения и ключевых параметров.

---

## 1. Коммуникации и Уведомления

| Сервис | Назначение | ID / Ключи (ENV) |
| :--- | :--- | :--- |
| **Whapi.cloud** | Проверка существования номеров в WhatsApp (WhatsApp Check API) | `WHAPI_TOKEN` |
| **Resend** | Отправка транзакционных писем (регистрация, подтверждение оплаты) | `RESEND_API_KEY` |
| **Telegram Bot API** | Прямые интерактивные уведомления с кнопками «Взять лид» | `TELEGRAM_BOT_TOKEN` |
| **Make.com** | Резервный канал уведомлений и сложные сценарии логики | `MAKE_WEBHOOK_URL` |

## 5. Инфраструктура

---

> [!TIP]
> **Важное замечание**: Все API-ключи хранятся в файле `.env` на сервере и локально. Никогда не передавайте их в открытом виде и не коммитьте в публичный репозиторий.
